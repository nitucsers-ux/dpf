\begin{abstract}\noindent
This supplementary document accompanies the main paper. It embeds the
\emph{complete raw research dataset} produced by every experiment, the
per-trial measurements supporting the medians reported in the main
text, the deterministic seeds and software environment needed to
reproduce every numeric value, and a brief honest-claims audit of the
manuscript. All cross-references with the prefix ``S\,$\cdot$'' (e.g.\
Table~S2) refer to items in this document. The accompanying code
repository, raw CSV files, and unit tests are released under the MIT
License at the URL listed in the main paper's \emph{Data
Availability} statement.
\end{abstract}

With the release tarball extracted, every table and figure in the
main paper is regenerated by:
\begin{lstlisting}[basicstyle=\ttfamily\small, frame=none, backgroundcolor=\color{white}, numbers=none]

$ python -m experiments.run_all
$ pytest tests/ -v
\end{lstlisting}

\Cref{sec:raw-csv} verbatim; \texttt{pytest} verifies bit-exact
reproducibility against the values listed below.

\paragraph{Derived statistics (verified by the unit tests).}
For the AI / in-distribution row:
accuracy $= (\mathrm{TP}+\mathrm{TN}) / 400 = (172+174)/400 = 0.8650$;
FPR $= \mathrm{FP}/(\mathrm{FP}+\mathrm{TN}) = 26/200 = 0.130$;
recall $= \mathrm{TP}/(\mathrm{TP}+\mathrm{FN}) = 172/200 = 0.860$;
precision $= \mathrm{TP}/(\mathrm{TP}+\mathrm{FP}) = 172/198 = 0.869$.
The 95\,\% Wilson confidence interval on accuracy at $n\!=\!400$
spans $[83.0\,\%, 89.5\,\%]$. This means the
$+2.8$ percentage-point boost from the human panel
($89.3\,\%\!-\!86.5\,\%$) is \emph{within} the AI-only confidence
interval, so the boost is not statistically distinguishable from
noise at this sample size. A larger panel and a larger test split
($n\!\geq\!1\,000$) would be needed to bound it tightly. This caveat
is also stated in the discussion of Section\,5.6 of the main paper.

\paragraph{The cross-distribution direction is reversed.}
The cross-distribution accuracy (92.3\,\%) is higher than the
in-distribution accuracy (86.5\,\%), which is the \emph{opposite}
of the typical literature finding. The reason is that our
cross-distribution generator applies the deepfake artefact
\emph{twice} (lines 18--19 of
\texttt{data/generate\_synthetic.py}'s \texttt{CrossDistFake}
function), which strengthens the brightness, boundary, and
high-frequency cues that the frequency-domain features pick up on.
This is a known limitation of synthetic-deepfake benchmarks. A real
cross-pipeline shift (e.g.\ FaceSwap-trained / Wav2Lip-tested)
would almost certainly show the opposite direction --- the main
paper Section\,5.6 (D2) is explicit about this caveat. Do not read
the cross-distribution row as a generalisation upper bound; read it
as a sanity check that the framework returns sensible verdicts on a
strictly different distribution.
